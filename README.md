# Crypto Trading Journal

A personal crypto trading workspace with journal, watchlist, weekly setups, and rules. Data saves locally in your browser.

## Deploy to Vercel (Free) — Step by Step

### 1. Install Node.js
Download from https://nodejs.org (choose LTS version)

### 2. Install dependencies
Open a terminal in this folder and run:
```
npm install
```

### 3. Push to GitHub
- Go to github.com and create a free account
- Create a new repository called "trading-journal"
- Run these commands in this folder:
```
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/trading-journal.git
git push -u origin main
```

### 4. Deploy on Vercel
- Go to vercel.com and sign up with your GitHub account
- Click "Add New Project"
- Import your "trading-journal" repository
- Click Deploy — done!

You'll get a free link like: https://trading-journal-xxx.vercel.app

### Your data
All trades, watchlist, setups, and rules save in your browser's localStorage automatically. Nothing is lost between visits.
